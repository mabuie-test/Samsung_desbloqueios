Guia rápido - Windows
=====================

1. Pré-requisitos
-----------------
- Windows 10/11 64 bits.
- Python 3.10+ instalado e adicionado ao PATH.
- Microsoft Visual C++ Build Tools (para compilar dependências nativas).
- Drivers Samsung/ADB e libusb instalados (Samsung USB Driver e Zadig, quando necessário).

2. Instalar dependências
-----------------------
- Abra o "Prompt de Comando" ou PowerShell na pasta do projeto.
- Crie (opcional) um ambiente virtual: `python -m venv .venv && .venv\\Scripts\\activate`.
- Instale os requisitos: `pip install -r requirements.txt`.

3. Extração e neutralização de firmware
---------------------------------------
- Coloque pacotes brutos em `firmware/raw/` (qualquer extensão suportada: `.tar.md5`, `.tar`, `.zip`, `.pac`, `.nb0`, `.bin`).
- Para verificar e extrair manualmente um `.tar.md5`: `python -m modules.firmware.tar_md5_extractor --input firmware/raw/SEU_ARQUIVO.tar.md5 --dest firmware/extraido`.
- Para sanitizar, remover apps Google/MDM, neutralizar FRP e repacotar automaticamente:
  - Via GUI: abra a aba **Firmware**, escolha o pacote e clique em **Sanitizar Samsung** ou **Neutralizar Multi-Marca**.
  - Via script direto (exemplo): `python - <<"PY"` seguido de `from modules.firmware.neutralizer import FirmwareNeutralizer; FirmwareNeutralizer().neutralize_archive(Path('firmware/raw/SEU_ARQUIVO.tar.md5'))`.
- Pacotes assinados compatíveis com Odin são gerados em subpastas `firmware/<perfil>/sanitized/`.

4. Execução da interface
------------------------
- GUI PyQt5: `python main.py --gui qt` (integra todas as rotinas compartilhadas).
- GUI Tkinter clássica: `python main.py --gui tk`.
- Linha de comando direta: `python main.py --cli --model SM-A146B --connection adb --serial SEU_SERIAL`.

5. Empacotamento (build Windows)
--------------------------------
- Opcional: gere um executável com PyInstaller: `python scripts/package_app.py --onefile`.
- O binário aparecerá em `dist/` já preparado para não ser rejeitado pelo Odin.

6. Dicas para desbloqueio
-------------------------
- Conecte o aparelho com drivers instalados e depuração USB ativada.
- Para fluxos com test-point (EDL/MTK), coloque o dispositivo em curto conforme o modelo e conecte o cabo USB antes de iniciar a ferramenta.
- Utilize cabos de boa qualidade e portas USB 2.0 para maior estabilidade.
- Aproveite a neutralização automática para remover FRP/MDM direto do pacote de firmware antes do flash.

7. Limpeza e logs
-----------------
- Logs são gravados em `samsung_unlock.log`.
- Para resetar configurações temporárias, remova a pasta `.cache` gerada na raiz do usuário ou limpe `backups/`, `firmware/raw/` (originais) e `firmware/*/sanitized` (gerados).
