Como compilar e executar a versão nativa em C
============================================

Pré-requisitos
--------------
- Linux com GCC/Clang e `make` instalados.
- Pacotes de desenvolvimento do libusb (`libusb-1.0-0-dev` em Debian/Ubuntu).
- ADB (Android Platform Tools) no PATH para comandos de debug.

Compilação
----------
1. Entre na pasta `native`:
   ```bash
   cd native
   ```
2. Instale dependências (exemplo no Debian/Ubuntu):
   ```bash
   sudo apt-get update && sudo apt-get install -y build-essential libusb-1.0-0-dev adb
   ```
3. Compile o binário:
   ```bash
   make
   ```
   O executável `samsung_unlock` será gerado na mesma pasta.
   Caso o libusb de desenvolvimento não esteja presente, o binário é gerado com
   stubs para USB/EDL apenas para fins de compilação; instale `libusb-1.0-0-dev`
   para ter acesso às operações nativas.

Execução
--------
- Exibir ajuda e opções disponíveis:
  ```bash
  ./samsung_unlock --help
  ```
- Rodar diagnóstico rápido do ambiente:
  ```bash
  ./samsung_unlock --diag
  ```
- Listar dispositivos conectados via ADB:
  ```bash
  ./samsung_unlock --list
  ```
- Varredura USB nativa (usa libusb, útil para confirmar VID/PID em EDL):
  ```bash
  ./samsung_unlock --usb-scan
  ```
- Handshake EDL em dispositivos Qualcomm (exemplo VID/PID 05c6:9008):
  ```bash
  ./samsung_unlock --edl-handshake 05c6 9008
  ```
- Montar partição como leitura-escrita usando o módulo de kernel exposto:
  ```bash
  ./samsung_unlock --km-mount /system
  ```
- Definir flags internas no módulo de kernel:
  ```bash
  ./samsung_unlock --km-flag allow_rw
  ```
- Analisar ficheiros de log em busca de padrões de segurança:
  ```bash
  ./samsung_unlock --pm-scan /tmp/recovery.log
  ```
- Reiniciar um dispositivo (modos suportados: normal, recovery, download):
  ```bash
  ./samsung_unlock --reboot recovery
  ```
- Enviar ficheiro para o dispositivo:
  ```bash
  ./samsung_unlock --push caminho/local.zip /sdcard/local.zip
  ```
- Copiar ficheiro do dispositivo para o computador:
  ```bash
  ./samsung_unlock --pull /sdcard/log.txt ./log.txt
  ```
- Executar um comando direto no shell do dispositivo:
  ```bash
  ./samsung_unlock --shell "pm list packages"
  ```
- Ativar MTP junto com ADB (útil após alguns desbloqueios):
  ```bash
  ./samsung_unlock --enable-mtp
  ```

Limpeza
-------
- Para remover o binário gerado:
  ```bash
  make clean
  ```
